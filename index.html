Como Jogar

💡
Coloca uma lâmpada em cada linha, coluna e região colorida.
🚫
Lâmpadas não podem ser adjacentes — nem na diagonal.
👆
Toque/clique para alternar: vazio → ✕ (eliminar) → 💡 → vazio.
✕
Usa o ✕ para marcar células que não podem ter lâmpada.
💣
Colocar lâmpada num sítio impossível mostra 💣 Algo está mal — penaliza pontos no final.
⭐
Se a tua primeira lâmpada no tabuleiro estiver correcta, ganhas +50 pontos bónus (revelado no fim)!
📅
O Desafio Diário é o mesmo puzzle para todos — compara o teu tempo!
